# Mahfuz Ahammed Muzahid — Portfolio

A responsive personal portfolio built with React, Vite, Framer Motion and plain CSS.

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

Import this GitHub repository into Vercel. Vercel will detect Vite automatically.

- Build command: `npm run build`
- Output directory: `dist`
- Install command: `npm install`

## Personalize

- Replace `public/images/mahfuz-portrait.webp` to change the portrait.
- Edit the profile, skills, services and social links in `src/App.jsx`.
- The contact form currently opens the visitor's email app using a `mailto:` link. Connect a form service later if you want messages delivered without the visitor's email app.

## Notes

No fictional client projects, employers, project metrics or dated experience have been added. The Projects section is intentionally presented as a work-in-progress until real projects are available. Skill items are based on the reference portfolio and the profile details supplied by Mahfuz; adjust any technology that you do not personally use confidently.
